# تمرین پایتون ۱

در این پوشه مجموعه‌ای از تمرین‌های مقدماتی زبان برنامه‌نویسی پایتون قرار دارد.

### مباحث تمرین‌شده:

- دستور Print
- حلقه For
- حلقه While
- دستورات شرطی If
- عملیات ریاضی پایه
- حلقه‌های تو در تو (Nested Loops)
- محاسبه مجموع اعداد زوج
- شمارش معکوس
- رسم الگو با استفاده از حلقه‌ها

هدف این تمرین‌ها، آشنایی با مفاهیم پایه پایتون و تقویت مهارت برنامه‌نویسی است.
