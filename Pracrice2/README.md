# تمرین پایتون ۲

در این پوشه یک ماشین‌حساب ساده با زبان برنامه‌نویسی پایتون طراحی شده است.

### مباحث استفاده‌شده:

- دستور Match-Case (Switch)
- ساختار داده Dictionary
- عملیات ریاضی پایه
- دریافت ورودی از کاربر
- دستورات شرطی

هدف این تمرین، آشنایی با روش‌های مختلف پیاده‌سازی یک ماشین‌حساب در پایتون است.
